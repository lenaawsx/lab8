Что такое компонент, пропсы и состояние

Компонент — это независимая часть интерфейса (кнопка, форма, список), которую можно переиспользовать.
Пропсы — это данные, которые компонент получает «снаружи».
Состояние (state) — это данные внутри компонента, которые могут меняться и обновляют интерфейс.

Какую часть кода помог написать ИИ

ИИ помог написать структуру компонентов, функции обработки событий и оформление стилей. 

Что вы поняли о компонентном подходе

Компонентный подход делает код понятным: каждый элемент — отдельная логическая часть, которую легко менять, тестировать и использовать снова.
